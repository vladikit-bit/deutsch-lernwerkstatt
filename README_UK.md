# Deutsch-Lernwerkstatt для OpenCode (Termux / Android)

Стартовий персональний репетитор німецької на базі твоїх локальних матеріалів DaF kompakt A1–B1. Усередині — Agent Skill, навчальні slash-команди, словниковий шаблон, журнал прогресу та безпечніші інструменти для роботи з вибраними сторінками PDF. PDF-підручники не входять у чистий дистрибутив/репозиторій за замовчуванням: додай свої файли в `material/original/`. Локальна робоча копія може вже містити додані користувачем PDF — перевіряй фактичний вміст каталогу, а не вважай його автоматично порожнім.

## 1. Android-застосунок для роботи з PDF

**Перший варіант для тестування: PDFgear для Android** — https://play.google.com/store/apps/details?id=com.pdfeditor.pdfeditorandriod

За описом Google Play він підтримує виділення, підкреслення й закреслення тексту, довільні малюнки, текстові поля/нотатки, а також редагування тексту PDF; сторінка заявляє безкоштовне використання функцій. Перед роботою з підручниками перевір на копії одного PDF: збережи анотації, закрий файл, відкрий повторно й переконайся, що записи залишилися. Не використовуй хмарні AI-функції застосунку, якщо не хочеш передавати туди документи.

Для навчання зручно зберігати дві копії: `Kursbuch-original.pdf` (ніколи не змінювати) і `Kursbuch-annotated.pdf` (поточні помітки/відповіді). Не роби рукопис занадто дрібним: модель бачить лише те, що достатньо чітко відображається у зображенні.

## 2. Встановлення у Termux

1. Розпакуй архів, наприклад, у домашню папку Termux так, щоб проєкт був у `~/deutsch-lernwerkstatt`.
2. За потреби дозволь Termux доступ до спільного сховища: `termux-setup-storage`.
3. Установи Poppler для витягування тексту та рендерингу окремих сторінок:

   ```sh
   pkg update
   pkg install unzip poppler
   ```

4. Запусти OpenCode з кореня проєкту:

   ```sh
   cd ~/deutsch-lernwerkstatt
   opencode
   ```

Навичка `deutsch-tutor` і команди розташовані в `.opencode/`, за форматом OpenCode. Проєктний `opencode.json` просить підтвердження для змін файлів, shell-команд, а також для `webfetch` і `websearch` (окремі дозволи). Якщо команди не з'являються, переконайся, що OpenCode запущений саме з каталогу проєкту, і перевір `/help`.

## 3. Команди репетитора

- `/diagnostyka` — адаптивна діагностика A1–B1, питання по одному; якщо в журналі вже є актуальний прогрес, нова діагностика не починається автоматично.
- `/lektion A1 Begrüßung und Vorstellung` — одне сфокусоване заняття.
- `/quiz Artikel und Plural` — інтерактивна перевірка до 10 питань.
- `/erklaer Ich habe einen Termin` — пояснення фрази/граматики.
- `/vokabeln A1 Begrüßung` — словниковий набір і вправи на пригадування.
- `/wiederholung` — повторення лише того, що записане або реально вивчалось у чаті.
- `/wochenplan [тривалість/фокус]` — практичний план на 7 днів; без аргументів — 30–45 хвилин на день.
- `/perevir-pdf material/annotated/твоя-копія.pdf` — інструкція перевірити виконані вправи з доступних PDF/зображень; заміни шлях на реальний файл або прикріпи зображення сторінок у клієнті.

**Мовна політика:** українська — основна мова пояснень; англійська — додатковий місток, коли реально допомагає; російська — лише для доречного контрасту або за прямим проханням.

## 4. Текст PDF: витягнути вибрані сторінки

```sh
bash scripts/pdf-text.sh   "material/original/DaF-kompakt-A1-Kursbuch.pdf"   "material/text/a1-lektion-01.txt" 1 5
```

Заміни назву й номери сторінок на реальні. Скрипт не перезаписує наявний вихідний файл і не запускає OCR. Він призначений для PDF із текстовим шаром; порядок колонок, таблиці, IPA та умляути треба перевірити вручну.

## 5. Рукописні відповіді та малюнки

Звичайний `pdftotext` часто не може відтворити рукопис, штрихи, стрілки чи візуальні позначки. Для перевірки завдання підготуй зображення **лише потрібних сторінок**:

```sh
bash scripts/pdf-page-images.sh   "material/annotated/DaF-kompakt-A1-annotated.pdf"   "material/page-images/lektion-01" 1 3
```

Скрипт рендерить 1–6 сторінок за запуском у PNG 150 DPI та не перезаписує вже наявні `page-*.png` у заданому каталозі. Потім прикріпи PNG-зображення до повідомлення OpenCode (через доступний у твоїй версії спосіб додавання зображення) і використовуй модель/провайдера з підтримкою vision. Запусти `/perevir-pdf` і вкажи, що саме перевірити.

Якщо модель або провайдер не підтримує зображення, вона не зможе надійно оцінити рукопис із самого PDF-тексту. Тоді можна протестувати OCR на одній сторінці або надрукувати власні відповіді в чаті. Не допускай, щоб модель вгадувала нечитабельний почерк.

## 6. Навчальні дані

- `vocab/vokabeln.tsv` — машинозчитуваний словник.
- `progress/fortschritt.md` — журнал тем, помилок і наступного кроку.
- `material/original/` — оригінальні PDF; папка існує, але в чистому дистрибутиві PDF-підручників немає, тоді як локальна копія може містити додані файли — перевіряй фактичний вміст.
- `material/annotated/` — робочі копії з твоїми помітками; папка вже існує.
- `material/text/` — вибрані текстові витяги, а не повні копії підручників.
- `material/page-images/` — рендери окремих сторінок для візуальної перевірки.

У чистому репозиторії/дистрибутиві немає PDF-підручників; локальна копія може містити додані файли. Перевір `material/original/`, додай свої PDF, якщо їх там немає, і зберігай витяги в `material/text/`; без матеріалів команди працюють із загальними темами й не вигадують сторінки чи вправи.

Навчальні команди не мають змінювати словник, прогрес чи PDF без прямого прохання. Після справжнього заняття попроси асистента підготувати пропозицію оновлення прогресу, переглянь її та дозволь запис лише тоді, коли погоджуєшся.

## 7. Приватність та межі

OpenCode може локально зберігати навчальні файли, але якщо модель хмарна, переданий їй текст або зображення можуть надсилатися провайдеру. Не вважай локальність файлу доказом локальної обробки. Якщо використовуєш `websearch`, пошуковий запит теж може надсилатися зовнішньому провайдеру; не вводь у нього чутливі дані. Аналізуй лише сторінки, що потрібні для вправи, та не завантажуй цілий підручник без потреби. Рукописна перевірка залежить від чіткості зображення та підтримки vision конкретною моделлю.

## 8. Рекомендований перший запуск

1. Встанови PDFgear і протестуй анотації на копії однієї сторінки.
2. Відкрий Termux, перейди в `~/deutsch-lernwerkstatt` і запусти `opencode`.
3. Виконай `/diagnostyka`.
4. Після діагностики почни першу відповідну тему; конкретну Lektion DaF kompakt обери за фактично доступним матеріалом у `material/original/` (перевір каталог, а не припускай, що PDF немає).
5. Коли PDF доступні — додані раніше або зараз — візьми 1–3 сторінки вправ, заповни їх у PDFgear, збережи копію й протестуй `/perevir-pdf` з прикріпленими PNG.

Рекомендований темп на старті — 30–45 хвилин на день. Краще одна перевірена тема та активне пригадування, ніж багато сторінок, які лише перечитано.
